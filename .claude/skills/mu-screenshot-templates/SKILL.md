# Образцы для бота из скриншота

Скриншоты от пользователя приходят файлами (путь в сообщении, обычно `.../images/N.png|webp`).

## Куда класть

| Что | Папка | Имя |
|---|---|---|
| Кнопки, окна, надписи интерфейса и лаунчера | `murdrum-bot/templates/` | `<экран>_<элемент>.png`: `launcher_connect.png`, `dialog_ok.png`, `disconnect_text.png`, `server_select_title.png` |
| Вещи, которые бот оставляет (камни и т.п.) | `murdrum-bot/keep/` | `bless.png`, `soul.png`, `chaos.png`, `life.png`, `creation.png`, `guardian.png` |
| Вещи, которые бот выбрасывает | `murdrum-bot/junk/` | по названию вещи латиницей |

## Как резать

1. Открой картинку через PIL, выведи размер. Посмотри на неё (Read), найди элемент.
2. Сначала вырежи с запасом во временный файл в scratchpad и посмотри (Read), потом уточни рамку. Не угадывай координаты с первого раза.
3. Правила вырезки:
   - **Интерфейс:** только сам элемент без фона мира вокруг (фон меняется → поиск ломается). Текст — плотно по буквам.
   - **Вещи в инвентаре:** вещи — 3D-модели, рисуются поверх ячейки. Вырезай **середину** вещи, меньше одной ячейки (примерно 60–70% ячейки), без рамки ячейки и без цифр количества/уровня.
   - Без курсора мыши и всплывающих подсказок в кадре.
4. Сохраняй **PNG** (`.convert("RGB")`), даже если исходник `webp`/`jpg`.
5. Проверь итог (Read каждого файла).

## Масштаб

У пользователя игра 1024×768 в окне при масштабе Windows 125% — на скриншоте окно ~1280×960.
- Запиши в коммит-сообщение, из какого размера окна вырезан образец (ширина клиентской области на скриншоте).
- Если на скриншоте видно всё окно игры, клиентская область — это окно без заголовка (полоса с `MU` сверху).
- Бот должен искать образцы с учётом масштаба: размер_окна_сейчас / размер_окна_на_скриншоте.

## После

- Обнови таблицу образцов в `murdrum-bot/README.md`, если добавлен новый тип.
- Закоммить только образцы (не исходный скриншот целиком — на нём может быть личная информация: логин, рабочий стол).
