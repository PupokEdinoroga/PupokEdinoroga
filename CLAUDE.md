# CLAUDE.md

Общение с владельцем репозитория — на русском.

## Что здесь

- `README.md` — профиль GitHub (не трогать без просьбы).
- `murdrum/index.html` — браузерный кликер-игра (один файл, без сборки).
- `murdrum-bot/` — внешний фарм-бот для MU Online сервера **Murdrum** (владелец репозитория = владелец сервера, бот для теста, правила сервера планируется поменять).
  - `murdrum-bot.ahk` + `settings.ini` — текущая версия на AutoHotkey v2 (Windows). Здесь не запускается — проверять синтаксис AHK v2 вручную и внимательно.
  - `tools/mu_data.py` — расшифровка данных клиента: `EncTerrainN.att` (MapFileDecrypt + BuxConvert) → сетки 256×256, `Movereq.bmd`, A*-поиск пути, `drop_spot`.
  - `maps/*.att` — уже расшифрованные сетки проходимости (флаги: 0x01 безопасная зона, 0x04 стена, 0x08 пустота), `maps/movereq.json` — список /move.
  - `templates/*.png` — образцы для поиска на экране (кнопка connect лаунчера, окно дисконнекта, OK), вырезаны из скриншотов пользователя.
  - `keep/`, `junk/` — образцы вещей, которые бот оставляет / выбрасывает.

## Факты о клиенте (проверено)

- Клиент MU 1.04d (Season 2), окно с заголовком `MU`, лаунчер `MurdrumLauncher.exe` v2.09 помнит логин, вход — кнопка `connect`.
- Игра в окне **1024×768**, но масштаб Windows у пользователя **125%** → окно физически ~1280×960. Все координаты/образцы пересчитывать от реального размера клиентской области.
- `Main.exe` и лаунчер упакованы; nProtect GameGuard фактически отсутствует (нет GameGuard/, GameMon.exe). Защиту пользователь отключать не хочет.
- Вещи в инвентаре — 3D-модели, иконок в файлах нет: образцы вещей только со скриншотов.
- Dungeon 1/2/3 на карте не связаны — переход между ними через `/move`.

## Правила

- Файлы клиента (`*.exe`, `*.dll`, `Data/`) не коммитить. Клиент распаковывать в scratchpad (`innoextract`), не запускать.
- Логин/пароль не коммитить: в `murdrum-bot/settings.ini` в репозитории поля `Login`/`Password` остаются пустыми (поддержка отдельного `settings.local.ini` пока не сделана, имя уже в .gitignore).
- Скриншоты от пользователя приходят файлами — из них можно вырезать образцы через PIL.
- После правок `tools/mu_data.py`: `cd murdrum-bot/tools && python3 mu_data.py --path lorencia 130 130 180 120` (ожидается путь ~51 клетка).
- Известные проблемы бота и план переписать его на Python с распознаванием экрана — см. историю ревью (senior-code-reviewer): защита режима keep без образцов, DPI, вещь на курсоре, проверка открытого инвентаря, подключить `templates/` к детекту дисконнекта.
